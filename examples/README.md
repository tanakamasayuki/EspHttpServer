# EspHttpServer examples

> 日本語版: [README.ja.md](README.ja.md)

## Workflow and individual READMEs

Start with the [example workflow](../docs/GUIDE_EXAMPLES.md), then choose the relevant sketch.

A useful starting point is [BasicDynamic](BasicDynamic/README.md). Check its required hardware and choose another entry below if it does not match your setup.

| Example | Learn |
|---|---|
| [BasicDynamic](BasicDynamic/README.md) | Return text from a dynamic HTTP route |
| [ChunkedStream](ChunkedStream/README.md) | Send and finish a chunked HTTP response |
| [CookieSimple](CookieSimple/README.md) | Read, set and clear a browser cookie |
| [EmbeddedAssetsSimple](EmbeddedAssetsSimple/README.md) | Serve assets compiled into the firmware |
| [ErrorHandling](ErrorHandling/README.md) | Customize error and not-found responses |
| [FormParamsSimple](FormParamsSimple/README.md) | Read URL-encoded form fields from a POST request |
| [LoginPlainBind](LoginPlainBind/README.md) | Demonstrate login state and HTML data binding |
| [MultipartParamsSimple](MultipartParamsSimple/README.md) | Consume multipart form fields and uploaded content |
| [PathParams](PathParams/README.md) | Extract values from a matched route path |
| [QueryParamsSimple](QueryParamsSimple/README.md) | Read and enumerate URL query parameters |
| [SessionSimple](SessionSimple/README.md) | Create and clear cookie-based session identifiers |
| [StaticFS](StaticFS/README.md) | Serve mounted filesystem content and memory assets |
| [TemplateHead](TemplateHead/README.md) | Fill templates and insert content into HTML head |
