# EspHttpServer サンプル

> English: [README.md](README.md)

## 実行ガイドと個別README

最初に[サンプル入門ガイド](../docs/GUIDE_EXAMPLES.ja.md)を読み、目的に合う例へ進んでください。

最初の候補は[BasicDynamic](BasicDynamic/README.ja.md)です。必要な機器を確認し、対象が異なる場合は下の一覧から選び直してください。

| 例 | 学ぶこと |
|---|---|
| [BasicDynamic](BasicDynamic/README.ja.md) | 動的HTTPルートから文字列を返す |
| [ChunkedStream](ChunkedStream/README.ja.md) | HTTP応答を分割送信して完了させる |
| [CookieSimple](CookieSimple/README.ja.md) | ブラウザのCookieを読み・設定し・削除する |
| [EmbeddedAssetsSimple](EmbeddedAssetsSimple/README.ja.md) | ファームウェアに埋め込んだ素材を配信する |
| [ErrorHandling](ErrorHandling/README.ja.md) | ErrorとNot Foundの応答を変更する |
| [FormParamsSimple](FormParamsSimple/README.ja.md) | POSTされたFormの項目を読み取る |
| [LoginPlainBind](LoginPlainBind/README.ja.md) | ログイン状態とHTMLへのデータ反映を試す |
| [MultipartParamsSimple](MultipartParamsSimple/README.ja.md) | MultipartのForm項目とアップロードを読み取る |
| [PathParams](PathParams/README.ja.md) | 一致したルートのPathから値を取り出す |
| [QueryParamsSimple](QueryParamsSimple/README.ja.md) | URLのQuery項目を読み出し列挙する |
| [SessionSimple](SessionSimple/README.ja.md) | CookieによるSession識別子を作り削除する |
| [StaticFS](StaticFS/README.ja.md) | mountしたFSの内容とメモリ素材を配信する |
| [TemplateHead](TemplateHead/README.ja.md) | Templateを埋めてHTML headへ内容を挿入する |
